# Buildora — AI-Powered Website Builder

Buildora is a full-stack web application that helps users create websites using natural-language prompts. Powered by the Google Gemini API, it generates website code based on user requirements and provides a frontend preview to make website creation easier and faster.

## Features

- **AI-Powered Code Generation:** Generate website code from text prompts using the Gemini API.
- **Live Website Preview:** Preview generated websites through the frontend.
- **User Authentication:** Sign up and log in to access the application.
- **Full-Stack Architecture:** Built with a React frontend and a Node.js/Express backend.
- **Database Integration:** Uses MongoDB for application data.

## Tech Stack

- **Frontend:** React, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **AI Integration:** Google Gemini API
- **Deployment:** Render

## Getting Started

1. Clone the repository.
2. Install the frontend and backend dependencies.
3. Configure the required environment variables.
4. Start the backend and frontend development servers.
5. Enter a prompt in Buildora and generate your website.

## Project Goal

The goal of Buildora is to simplify website development by allowing users to describe their ideas in natural language and use AI-generated code as a starting point for building websites.
